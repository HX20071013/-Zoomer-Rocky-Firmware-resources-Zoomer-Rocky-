这是Paw Patrol Zoomer Rocky二次开发项目的第二部分，固件资源。
我对原装主板进行了硬件分析，除了上一个模块提到的COB牛屎芯片，原装主板还包括了两个H桥电机驱动芯片，每个芯片管理一个电机
然而，真正重要的是：一个0.5GB容量的25系列SPI FLASH。这是一个容量庞大的容器，里面存储的是Zoomer Rocky全部的预设资源。这些资源中，最重要的其实是包装盒上标注为150+条的音频资源
有了这些资源，就可以构建自己的RVC变声模型，也可以用于开发新的动作体系，这也是整套设备在我认为最重要的部分
然而，很可惜的是，不知道是官方出于节约资源还是其他设计上的目的，Zoomer Rocky虽然有个舞蹈功能，但是两首舞曲分别只有20秒左右，在我看来，对于新系统的开发，这是急需补充的重要资料。并且，我的硬件资源也更充足：STM32F103RET6本身拥有储存空间，可以存储部分甚至全部运动控制、微动开关检测、音量开关检测、语言开关检测等模块的程序，而SPI FLASH除了继续使用官方的0.5GB，也可以使用更大的，并且由于官方和我的项目使用的都是标准储存器，不同型号可以替换
于是，为了补充舞蹈功能，使用完整资源，我查找了官方宣传文档，发现了两首歌的曲目信息已经写在宣传文档中：《Paw Patrol》和《Pup Pup Boogie》。借助中国庞大的MAD社区，我在Bilibili顺利找到了这两首音乐的完整资源，并通过cloudconvert转换成了STM32F1系列支持最好的.wav格式，一并上传
固件信息没有经过分析，包含动作、检测等其他资料，因此在分析时，务必注意，提取出的音频文件会包含英语和法语音频以及Rocky的狗叫声。对于训练RVC，请务必注意不要把狗叫声相关资源导入训练模型，以免出现不必要的混音和杂音。
由于Rocky的叫声已经包含多种情绪和状态，我认为我的项目不需要增加这些资源的数量，因此不打算对这些狗叫声资源做二次处理，如果有复刻者需要增加动物叫声资源，请用你们自己的方式扩展，如果可以的话，把你们的工具链分享在本项目下方帮助更多人！
